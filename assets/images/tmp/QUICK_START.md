# Quick Start: Adding Hero Image to Staff Dashboard

## Step 1: Add Your Image/GIF

Place your image or animated GIF file here with the exact name:
```
tmp.gif
```

**Location**: `assets/images/tmp/tmp.gif`

## Step 2: Supported Formats

Even though it's named `tmp.gif`, you can use:
- ✅ Animated GIF
- ✅ PNG image  
- ✅ JPG/JPEG image

Just name it `tmp.gif` regardless of actual format for this test.

## Step 3: Recommended Specifications

- **Width**: 1200px
- **Height**: 600px
- **Aspect Ratio**: 2:1 (landscape)
- **File Size**: Under 5MB for best performance
- **Quality**: High resolution for crisp display

## Step 4: Preview

The hero image will appear at the top of the staff home dashboard with:
- Full width display
- 200px height
- Rounded corners
- Shadow effect
- Graceful fallback if image fails

## Fallback Behavior

If `tmp.gif` is not found or fails to load:
- Shows a gradient background (navy blue)
- Displays placeholder icon and text
- No errors or crashes

## Testing

1. Place your `tmp.gif` in this folder
2. Restart the app
3. Navigate to Staff Dashboard (Home tab)
4. Hero image should appear at the very top

## Tips

- For animated GIFs: Keep file size under 2MB for smooth performance
- For static images: Use PNG for transparency, JPG for photos
- Landscape orientation works best (2:1 or 16:9 ratio)
- High contrast images look great with the shadow effect
