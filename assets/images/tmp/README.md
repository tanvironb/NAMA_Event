# Temporary Assets Folder

## Hero Image

Place your hero image or GIF here as `tmp.gif` for the staff dashboard.

### Supported Formats
- **Images**: PNG, JPG, JPEG
- **Animated**: GIF
- **Video**: (Future support for video formats)

### Recommended Specifications
- **Dimensions**: 1200x600 pixels (2:1 aspect ratio)
- **File Size**: Under 5MB for optimal performance
- **Format**: GIF for animations, PNG/JPG for static images

### Current File
- `tmp.gif` - Hero image for staff dashboard top banner

### Usage
The hero image is displayed at the top of the staff home dashboard with:
- Height: 200px
- Border radius: 16px
- Box shadow for depth
- Fallback gradient if image fails to load
