# Missing Files and Setup Guide

## Overview
This document outlines files that are intentionally excluded from version control for security reasons and provides setup instructions for new developers.

## Excluded Files (.gitignore)

### Firebase Configuration Files
These files contain project-specific API keys and configuration data that should not be committed to version control:

**Location: `/android/app/google-services.json`**
- Purpose: Android Firebase configuration
- Contains: Project ID, API keys, app IDs for Android platform
- How to obtain: Download from Firebase Console > Project Settings > General > Your apps > Android app
- Required for: Firebase services on Android (Auth, Firestore, Functions, etc.)

**Location: `/ios/Runner/GoogleService-Info.plist`**
- Purpose: iOS Firebase configuration  
- Contains: Project ID, API keys, app IDs for iOS platform
- How to obtain: Download from Firebase Console > Project Settings > General > Your apps > iOS app
- Required for: Firebase services on iOS

**Location: `/ios/firebase_app_id_file.json`**
- Purpose: iOS Firebase app identification
- How to obtain: Generated automatically when setting up iOS in Firebase Console

**Location: `/lib/firebase_options.dart`**
- Purpose: Dart/Flutter Firebase configuration
- Contains: All platform configurations in Dart format
- How to obtain: Run `flutterfire configure` command after setting up Firebase CLI
- Required for: Firebase initialization in Flutter app

### Cloud Functions Security Files
**Location: `/functions/.env*`**
- Purpose: Environment variables for local development
- Contains: Local configuration overrides, test keys
- How to obtain: Create manually if needed for local testing

**Location: `/functions/serviceAccountKey.json`**
- Purpose: Firebase Admin SDK service account key
- Contains: Private key for server-side Firebase operations
- How to obtain: Firebase Console > Project Settings > Service Accounts > Generate new private key
- Note: Only needed for local development/testing. Production uses automatic service accounts.

**Location: `/functions/.runtimeconfig.json`**
- Purpose: Firebase Functions runtime configuration
- Contains: Environment-specific configuration
- How to obtain: Set using `firebase functions:config:set` command

## Setup Instructions for New Developers

### 1. Firebase Project Setup
1. Contact project admin for Firebase project access
2. Install Firebase CLI: `npm install -g firebase-tools`
3. Login to Firebase: `firebase login`
4. Set project: `firebase use events-app3`

### 2. Flutter Firebase Setup
1. Install FlutterFire CLI: `dart pub global activate flutterfire_cli`
2. Configure Firebase for Flutter: `flutterfire configure`
3. Select existing project: `events-app3`
4. Select platforms: Android, iOS, Web

### 3. Platform-Specific Configuration

**Android:**
1. Download `google-services.json` from Firebase Console
2. Place in `/android/app/` directory
3. Ensure file is not committed to Git

**iOS:**
1. Download `GoogleService-Info.plist` from Firebase Console  
2. Place in `/ios/Runner/` directory
3. Add to Xcode project through Xcode IDE
4. Ensure file is not committed to Git

### 4. Cloud Functions Setup
1. Navigate to functions directory: `cd functions`
2. Install dependencies: `npm install`
3. Build functions: `npm run build`
4. Test locally: `npm run serve`

### 5. Development Environment Variables
Create `.env` files in functions directory if needed for local testing:
```
# functions/.env.local
SOME_API_KEY=your_local_test_key
DEBUG_MODE=true
```

## Security Notes

### What's Safe to Commit
- `firebase.json` - Project configuration
- `.firebaserc` - Project name reference
- `firestore.rules` - Database security rules
- `firestore.indexes.json` - Database indexes
- Cloud Functions source code (`/functions/src/`)
- Build configuration files

### What Must Never Be Committed
- Any file containing API keys or secrets
- Service account JSON files
- Platform-specific configuration files
- Environment variable files with sensitive data

### Current Project Security
- All sensitive files are properly excluded via .gitignore
- Cloud Functions use automatic Firebase service accounts (no manual keys needed)
- Firebase configuration uses public project references only

## Verification Checklist
Before first run, ensure you have:
- [ ] `android/app/google-services.json` (if building for Android)
- [ ] `ios/Runner/GoogleService-Info.plist` (if building for iOS)  
- [ ] `lib/firebase_options.dart` (generated by flutterfire configure)
- [ ] Functions dependencies installed (`npm install` in functions folder)
- [ ] Firebase CLI authenticated and project selected

## Troubleshooting

**Firebase not initialized error:**
- Check `lib/firebase_options.dart` exists
- Verify `flutterfire configure` was run successfully

**Google Services plugin error (Android):**
- Ensure `google-services.json` is in correct location
- Check file is not corrupted

**Build errors in functions:**
- Run `npm run build` in functions directory
- Check TypeScript compilation errors

**Permission denied errors:**
- Verify Firebase CLI is logged in with correct account
- Check project permissions in Firebase Console
